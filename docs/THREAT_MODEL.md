# KYRO threat model — STRIDE

Scope: browser/API, local database, repository ingestion, scanner/parser containers, model endpoint, agent workspace and GitHub delivery. Trust boundaries: browser → backend, GitHub/archive → repository parser, repository/model output → agent policy, worker → Docker daemon, execution container → host, backend → model/advisory/GitHub services.

Likelihood/impact are engineering estimates, not measured incidence. L/M/H = low/medium/high. Residual risk is explicit; this initial local deployment is not a hostile multi-tenant platform.

| ID / STRIDE | Asset, attack surface and scenario | Likelihood / impact / severity | Mitigation | Residual risk | Test case |
|---|---|---|---|---|---|
| T01 Tampering | Source archive traverses paths or injects links into host files | M/H/H | Bounded safe extraction, no links/special files, checked root | Parser bugs, archive size exhaustion | test_path_traversal; test_archive_link_blocked |
| T02 Elevation/Tampering | Repository prompt tells agent to expose keys or alter policy | H/H/H | Untrusted-data system instruction plus schema, path, command and approval boundaries | Model may create a logically poor in-scope patch | test_prompt_injection_cannot_expand_scope; live patch review |
| T03 Elevation | Malicious dependency/test executes arbitrary code | H/H/H | Tests only in restricted non-root networkless Docker; trusted images | Kernel/container runtime exploit | Live sandbox probe; command policy tests |
| T04 Elevation | Model attempts shell, host Docker or arbitrary commands | M/H/H | Array-only allowlist, no shell, no host repository execution | Approved project scripts are still hostile inside the container | test_unsafe_commands_blocked |
| T05 Elevation | Container escape reaches shared kernel/daemon | L/H/H | Capabilities dropped, no-new-privileges, process/memory/CPU limits, no socket in execution | Shared kernel, runtime CVEs; no gVisor proof | Live mount/network/root-write checks; infrastructure review |
| T06 Disclosure | Keys appear in source, logs, browser or model context | M/H/H | Backend env, credential encryption, secret redaction, omitted secret paths, no provider logging | Hardcoded custom secret patterns may be missed; caches sensitive | test_redacts_secret_patterns; source review/audit |
| T07 Spoofing/Elevation | GitHub token used for unauthorized repo writes | M/H/H | Selected-repository App preferred, backend token, explicit delivery approval, SHA/hash checks | Backend/socket compromise; broader OAuth scope | Owned object tests; GitHub contract tests; live access remains blocked |
| T08 Disclosure | Hostile repository exfiltrates code over network | H/H/H | Agent/test containers network none, no host secrets | Scanners require advisory egress, not domain-filtered | Live sandbox socket test; policy inspection |
| T09 Spoofing/Elevation | User guesses other owner repository/finding/job IDs | M/H/H | Backend owner traversal, owner-filtered queries, 404 | Single-operator DB/host access bypasses application controls | test_ownership; unauthorized endpoint tests |
| T10 Disclosure/Tampering | SQL injection or unauthorized DB access | M/H/H | SQLAlchemy bound queries, local DB/volume, migrations, no DB public port | Host access/backup leakage; SQLite encryption absent | Project CRUD/search validation and FK migration tests |
| T11 Tampering/Repudiation | Unsafe patch is published or merged without consent | M/H/H | Plan approval digest, independent report, verified hashes, draft PR approval, no merge API | Human can approve a flawed patch; semantic proof incomplete | Approval-change tests; mocked GitHub parent conflict; live PR blocked |
| T12 Denial of service | Huge archive/output/API requests or concurrent jobs exhaust RAM/disk | H/M/H | File/body/output limits, one worker, queue/rate limits, timeout/CPU/memory/pids | Caches/disk retention are operator-managed | test_payload_limits; process timeout tests; actual resource observations |
| T13 Denial of service | Agent loops or provider retries incur runaway work | M/M/M | Four-step ceiling, output/task token budgets, job/command timeouts, cancellation | Provider may continue processing briefly after disconnect | State graph/budget tests; live bounded execution |
| T14 Elevation/Disclosure | Scanner vulnerability triggered by malicious source | M/H/H | Version-pinned isolated image, read-only source, no credentials/caps | Trusted scanner needs network; parser/runtime CVEs possible | Adapter failure tests; actual version/readiness evidence |
| T15 Disclosure | Provider routing sends private code to billable cloud silently | M/H/H | LOCAL_ONLY endpoint validation, no cloud fallback, backend-only keys, explicit cost auth | Operator can configure unsafe external provider; Docker host gateway trusted | test_local_only; test_cloud_block_precedes_network |
| T16 Spoofing/Disclosure | Session theft, CSRF or XSS changes account/project | M/H/H | Argon2, HTTP-only/SameSite session, CSRF/origin, closed signup, CSP/React escaping | HTTP local traffic; trusted host compromise; no public TLS configured | test_bootstrap_and_csrf; cross-origin/header/cookie tests |
| T17 Elevation | API compromise abuses mounted Docker socket for host access | M/H/CRITICAL | Loopback deployment, trusted operator, dedicated Docker VM/host, no socket in execution | Backend has full daemon control by design; not solved by container flags | Deployment/mount review; dedicate engine before broader use |

The mitigation code and executed tests are evidence, not a security certification. Unexecuted live cases remain identified in IMPLEMENTATION_STATUS.md. Public deployment, team access, stronger isolation, egress restriction and automated retention require further work and authorization.
